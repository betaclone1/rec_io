# Cloud Workflow

This document provides a simple overview of a cloud-based development workflow.

## Basic Steps

1. Create or switch to a feature branch.
2. Make small, focused code changes.
3. Run local checks and tests where applicable.
4. Commit changes with clear commit messages.
5. Push the branch to the remote repository.
6. Open a pull request for review and merge.

## Notes

- Keep commits scoped to one logical change when possible.
- Prefer clear documentation for handoffs between environments.
- Verify deployments in a non-production environment first.
