# Regime learning initiative

Notes on regime detection, adaptation, and the longer-term initiative to have the system learn and adapt on its own to shifting regimes.

## Goal

Build toward: system that detects regime shifts and adapts (e.g. parameters, monitor settings, or strategy choice) based on data rather than manual tuning alone. Reusable backtest patterns and documented data pipelines support this.

## Current state

- Initiative scoped and owned by @analyst. No implementation yet.
- Dependencies: solid backtest patterns (01_backtest_patterns), strategy findings (02_strategy_findings), and coordination with @db for any schema or data needs and with PM for rollout.
