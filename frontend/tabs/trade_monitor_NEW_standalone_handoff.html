Trade Monitor NEW — standalone dev tab

Use this page on the same origin where you are already logged in (e.g. your main app after /login). It opens trade_monitor_NEW.html on your static dev server in a new tab and copies rec_auth_token, rec_user_no, and the main API origin via a URL fragment (not sent to the static server as a query string).

Saved in localStorage.tm_new_static_trade_monitor_base for next time. Default http://127.0.0.1:8091 matches the local orderbook static server when used.
